## Notes

- Bring a low-HP armor set for outside Jadoth so Caller can leave to handle the first waves of 360.

- When bringing the Mesmer trench pops to the glitch spot in Veil, try to pull left-side clover too. This enables the lord split: Tank + TK go to Monk lord, while Seeder + Caller + Emo go to Mesmer lord.
