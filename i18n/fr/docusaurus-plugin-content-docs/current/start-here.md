# Commencer ici

Si vous débutez en speed clear DoA, ne commencez pas par lire toutes les pages de tactique. Commencez par les bases, préparez un premier rôle, puis demandez un gear check avant de rejoindre un run teach.

## Votre Premier Objectif

Votre premier rôle sera généralement [Empathy](/tactics/4-mesmers-3-3/empathy).

Empathy est le rôle mesmer le plus simple pour commencer, mais il faut quand même le bon build, le bon gear, les consommables et les titres requis. Avant votre première run, préparez la base de [Mesmer gear](/tactics/gear/mesmer), puis demandez un gear check dans un Discord teach.

## Que Lire En Premier

Lisez ces pages dans cet ordre :

1. [Overview](/tactics/) pour comprendre ce qu'est DoA et ce que chaque zone demande à la team.
2. [Fundamentals](/tactics/fundamentals) pour la communication, le cast range, la gestion d'aggro et les notes de skills.
3. [Glossary](/tactics/glossary) quand un terme ou un callout n'est pas clair.
4. [3-3 Teaching overview](/tactics/4-mesmers-3-3) pour voir la composition beginner complète.
5. [Empathy role page](/tactics/4-mesmers-3-3/empathy) pour les détails de votre premier rôle.

## Avant De Rejoindre Une Run

- Rejoignez un Discord teach.
- Préparez le build Empathy.
- Préparez le gear mesmer, les pcons et les titres requis.
- Demandez un gear check avant de vous inscrire pour un run.

## Après Vos Premières Runs

Une fois que Empathy devient confortable, suivez la progression des rôles dans le [3-3 Teaching overview](/tactics/4-mesmers-3-3#progression-des-rôles). Ne vous pressez pas vers les tactiques avancées ; la plupart des erreurs deviennent plus faciles à corriger quand vos fondamentaux sont solides.
