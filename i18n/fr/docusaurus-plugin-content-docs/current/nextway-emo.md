## Notes

- En City Split, une fois que le TT pull down, commencez à marcher vers l'extérieur pour lui donner un bon placement afin de commencer le pull Jadoth.
- En Veil Split, allez avec IAU et MT à ranger hill. Une fois que MT annule la chaîne [Recall], déclenchez-la avec [Ebon Escape] sur le TK.
- Tuez l'elementalist lord avec IAU ; utilisez [con]Imperial Guard Reinforcement Order[/con] pour maximiser les dégâts de [Pain Inverter]. [Vidéo exemple](https://www.youtube.com/watch?v=Mgu6bqaLB34&t=849s)
