# MeMo

MeMo apporte [Healing Seed], du damage mesmer et le support pour derv hill.

## Build

[MeMo;OQNEAqwN+ioButpL4bw0LRxD]

## Gear

Utilisez la page partagée [Mesmer gear](/tactics/gear/mesmer) comme base.

## Notes

[Life Bond] sert uniquement à vous donner une énergie infinie entre Foundry room 3 et Veil. Lancez le sur Emo, puis Emo place [Balthazar's Spirit] sur vous.

### Gloom

- Attendez avec Necro avant de déclencher les mobs au début.
- Allez avec Emo en Gloom pour cap la rift après wave 8.
- Aidez sur Darknesses wave 3.

### Foundry

- Utilisez [Healing Seed] sur Emo en Foundry room 4 wave 2.
- Pingez les snakes jusqu'à ce que General soit libre, puis laissez Emo le faire.
- Essayez de seed TK avant le pull du Black Beast.

### City

- Placez [Visions of regret] sur la main ball avant de taper l'off-damage.
- Aidez sur tout le wall.

### Veil

- Seed pendant 360 : Emo pendant les melee waves, tank autrement.
- [Life Bond] TK avant le pull derv hill.
- Allez avec le tank tuer Monk Lord.
- Rejoignez votre team au Mesmer Lord.
- Seed Emo pour 3-3.
- Tuez le tendril le plus proche pendant le premier spike 3-3 et le tendril du milieu pendant le second.
