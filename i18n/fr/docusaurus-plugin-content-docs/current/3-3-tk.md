## Notes

- N'hésitez pas à demander de l'aide si l'off-damage est trop difficile à gérer à temps.
- Sur les grosses spikes, un seul [Energy surge] sur l'off-damage suffit : vous voulez seulement mettre les mobs sous 90% pour [Edge of extinction].
- Sur les petites spikes, comme pendant le 360, continuez à spike l'off-damage car [Edge of extinction] proc moins.
- Attendez patiemment que le dervish lord break aggro du TT et évitez le share aggro quand vous le pull avec votre bow.
- N'utilisez pas [Mistrust] sur l'ele lord avant qu'il ait utilisé [Sandstorm] sous votre [Pain Inverter].
- Tuez les tendrils dans l'ordre, le plus éloigné d'abord, pour faciliter le pull du main tank.
- Vous pouvez utiliser [Recall] pour break ou delay des ennemis, comme pour [safe la première snake](/tactics/in-depth-concepts#safing-first-snake-as-tk) en foundry.
- Comme vous avez [Recall], prenez vos coffres en dernier.
- Évitez de target les warriors avec [Energy Surge], car ils peuvent tomber à court d'énergie, ce qui réduit les damage.
