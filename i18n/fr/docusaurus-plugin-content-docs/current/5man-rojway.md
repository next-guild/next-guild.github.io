# 5man Rojway

Variante à cinq joueurs avec un Tank Ranger, un Caller Mesmer, un TK Smiter, un Seeder et un Emo.

## Rôles

| Rôle | Focus | Page |
| --- | --- | --- |
| Tank | Main tank de la run. | [Ouvrir le rôle](/tactics/5man-rojway/tank) |
| Caller | Caller Mesmer avec [Visions of Regret], [Edge of Extinction] et [Winnowing]. | [Ouvrir le rôle](/tactics/5man-rojway/caller) |
| TK | Moine Smiter avec [Ray of Judgment], [Pain Inverter] et [Recall]. | [Ouvrir le rôle](/tactics/5man-rojway/tk) |
| Seeder | Support avec [Seed of Life] et dégâts Smiting. | [Ouvrir le rôle](/tactics/5man-rojway/seeder) |
| Emo | Maintient les bonds avec le même build que le 5man Mezway. | [Ouvrir le rôle](/tactics/5man-rojway/emo) |

## Équipement

- Tank : [équipement Ranger](/tactics/gear/ranger), comme en 5man Mezway.

- Caller : [équipement Mesmer](/tactics/gear/mesmer).

- TK et Seeder : [équipement Smiter](/tactics/gear/smiting-monk). Seeder doit aussi prévoir une pièce de Faveur divine +3.

- Emo : même build que le [5man Mezway Emo](/tactics/5man/emo), avec l'[équipement Emo](/tactics/gear/emo) habituel.
