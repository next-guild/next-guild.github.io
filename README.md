# Guild Wars DoA Guild Website

This project is a React-based website built with Docusaurus.

## Getting started

1. Install dependencies:

```bash
npm install
```

2. Run locally:

```bash
npm start
```

3. Build for production:

```bash
npm run build
```

## Editing content

- Home page: `src/pages/index.js`
- Styling: `src/css/custom.css`
- Tactics pages: `docs/*.md`
- Sidebar navigation: `sidebars.js`

## Notes

- The site is intentionally dark with purple/pink neon accents.
- Placeholders are included for images and build links.
- You can add more tactic pages under `docs/` and update the sidebar.
